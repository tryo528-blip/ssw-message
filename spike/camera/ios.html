아이폰 · 인증서 설치

Safari만 사용하세요. 크롬(iOS)은 이 검증에 쓰지 않습니다. 자체 서명을 신뢰해야 카메라 API가 열립니다. 경고만 넘기면 보통 실패합니다.

  1. 아래 버튼을 눌러 구성 프로파일을 받습니다.
  2. 설정 → 일반 → VPN 및 기기 관리 → 받은 프로필 → 설치
  3. 설정 → 일반 → 정보 → 인증서 신뢰 설정 → SSW Camera Spike CA 전체 신뢰 켜기
  4. 아래 HTTPS 링크로 검증 페이지를 엽니다. 자물쇠가 보여야 합니다.
1. 구성 프로파일 받기 4. 검증 페이지 열기

프로파일이 안 받아지면 ca.cer 를 연 뒤 같은 설정 경로로 설치하세요. 검증이 끝나면 프로필을 삭제하면 됩니다.
