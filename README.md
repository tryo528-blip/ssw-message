# SSW Message

현장·외근용 보조 앱. 할일 메모와 사진을 사무실로 보내면 SSWCENTER ERP가 자동으로 수집해 갑니다.
ERP와 직접 연결하지 않고, 정해진 공간에 정해진 양식으로 떨궈두는 단방향 투입 도구입니다.

| | |
|---|---|
| 상태 | 설계 확정 · 서버 프로토타입 완료 · **카메라 실기 검증 대기** |
| 비용 | 0원 (서버 임대·스토어 등록비 없음) |
| 지원 | iPhone · Android (PWA, 홈화면 추가) |

---

## 무엇을 하는가

**1. 할일 메모** — 현장에서 자유롭게 적어 보내면 ERP가 정해진 양식으로 받아갑니다.

**2. 사진 전송** — 개인정보가 담긴 사진을 **휴대폰 갤러리에 남기지 않고** 사무실로 보냅니다.

두 번째가 이 프로젝트의 존재 이유입니다.

---

## 세 가지 제약과 해법

### 사진이 갤러리에 남으면 안 된다

흔히 쓰는 `<input type="file" capture>` 는 **OS 기본 카메라 앱을 호출**합니다.
삼성 등 OEM 카메라는 촬영본을 DCIM에 먼저 저장한 뒤 앱에 넘기므로 갤러리에 남습니다.

대신 `getUserMedia` 로 브라우저 안에서 프리뷰를 띄우고 `<canvas>` 로 프레임을 캡처하면,
**파일시스템을 한 번도 거치지 않고** 메모리에만 존재하다 전송 후 사라집니다.
덤으로 canvas 재인코딩 과정에서 EXIF(GPS·기기정보)가 전부 소멸합니다.

> 한계: 스크린샷은 웹으로도 네이티브로도 막을 수 없습니다. 운영 규칙으로 관리해야 합니다.

### 개인정보가 제3자 서버에 남으면 안 된다

클라우드를 쓰지 않습니다. 폰이 **사무실 PC와 직접 TLS**를 맺습니다.
관건이던 인증서는 무료 DDNS + Let's Encrypt로 해결했습니다.

그 위에 **E2E 암호화**를 얹어, 사무실 디스크에 놓인 수집 전 파일까지 암호문으로 만듭니다.
ECDH(P-256) + HKDF-SHA256 + AES-256-GCM — 전부 브라우저 기본 API입니다.

또한 **인터넷에 노출되는 수신 서버는 개인키를 갖지 않습니다.**
그 서버가 통째로 털려도 사진은 복호화되지 않습니다.

```
인터넷 ──▶ receiver  ──▶ 암호문 ──▶ collector ──▶ 평문 ──▶ ERP
           개인키 없음                개인키 보유 · 미노출
```

### 비용이 들면 안 된다

아이폰 네이티브 배포는 연 $99가 고정 지출입니다. 그래서 **PWA**로 만듭니다.
홈화면에 추가하면 앱처럼 동작하고, 업데이트는 새로고침이면 끝입니다.
서버는 사무실 PC 1대이고 외부 임대가 없습니다.

## 빠른 시작 (로컬)

Node만 있으면 됩니다. **외부 패키지 0개** — `npm install` 이 필요 없습니다.

```bash
node server/keygen.mjs office
```

```bash
node server/keygen.mjs device 홍길동
```

```bash
node server/receiver.mjs --port 8443
```

다른 터미널에서 폰 시뮬레이터로 검사합니다.

```bash
node server/test-client.mjs --url http://localhost:8443
```

```bash
node server/collector.mjs
```

`server/inbox/ready/` 에 복호화된 평문이 떨어지면 정상입니다.

사무실에 실제로 설치하려면 [docs/SETUP.md](docs/SETUP.md) 를 따르세요.

## 검증 현황

**서버 (완료)** — `test-client.mjs` 9/9 통과.
정상 전송, 멱등 재전송, id 위조 거부, 암호문 변조 거부, 재전송 공격 거부,
미등록 기기 거부, 규격 위반 거부, 레이트리밋.
복호화 결과가 원본과 바이트 단위로 일치하고, 암호문 보관소를 평문 검색하면 0건입니다.

**암호화 (완료)** — 300KB 사진 기준 암호화 1ms, 전송량 증가 93바이트.

**카메라 (대기)** — 아이폰·갤럭시 실기에서 "촬영 후 갤러리에 안 남는다"를 확인해야 합니다.
**이 검증이 프로젝트 성패입니다.** 여기서 실패하면 설계 전제가 깨집니다.
